# Project Skills

## Intended scope

Install or update selected language, framework, and tooling skills in the target
repository. Keep reusable skill sources in dotagents; project installations
belong to the consuming repository rather than the user's global skill directory.

## Current behavior

This skill is a skeleton. When invoked, state that project installation and
update behavior is not implemented yet and briefly explain the intended scope.
Do not install, update, remove, or link skills, change project configuration,
or claim that setup has completed.

Installation commands, selection profiles, update handling, and verification
will be defined in a later implementation.
