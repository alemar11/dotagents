# SE2 Idea Body Template

Use this template only after the candidate name, tracker owner, and portable
source evidence are resolved. Keep the wording tentative and record unknowns
instead of inventing decisions.

## Canonical body

```markdown
## Summary

<One concise description of the proposal.>

## Problem or Opportunity

<The observed need, pain point, opportunity, or motivation.>

## Proposed Direction

<The tentative direction discussed, without turning it into a detailed plan.>

## Expected Value

<The outcome or benefit the proposal may provide.>

## Known Context and Constraints

- <Accepted context or constraint.>

## Open Questions

- <Unresolved question, or `None recorded.`>

## Source

- <Portable conversation, document, issue, or repository evidence.>
```

The hosted title supplies `Idea: <Name>`. No additional hosted classification
is required; leave native Issue Type unset.

## Capture limits

- Preserve the exact section order.
- Use `None recorded.` when no open question remains.
- Render Source through the shared
  [hosted-content-safety.md](../../../references/hosted-content-safety.md)
  contract. For Idea-specific provenance, prefer a hosted link, qualified issue
  ref, repository-relative source, or concise relevant conversation description.
- Do not add planning outcomes, goals, non-goals, acceptance criteria,
  implementation steps, dependencies, delivery policy, readiness claims,
  memory handoffs, or Feature fields.
