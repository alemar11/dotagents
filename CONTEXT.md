# Context

## Project Purpose

This repository maintains reusable tool skills (most ship a CLI under the
standard in `skills/skill-cli-creator/references/standard.md`) and
project-maintainer skills. `README.md` describes the catalog; `AGENTS.md` owns
repository-wide maintenance rules.

Engineering workflows (planning, review, implementation, Git and GitHub
delivery, repository knowledge) moved to the `swe` Claude Code plugin in
`alemar11/mechanica` and are no longer kept here. Skill-local references own
their contracts.
