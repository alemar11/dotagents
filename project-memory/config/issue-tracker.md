# Issue Tracker

## Configuration

| Key | Type | Value | Allowed values | Meaning |
| --- | --- | --- | --- | --- |
| `tracker_backend` | enum | `github` | `github`, `local` | Feature Specs, implementation issues, and Ideas are stored in GitHub Issues. |

GitHub Issues in `alemar11/dotagents` are authoritative. Repository-local
planning mirrors are not created for hosted artifacts.
